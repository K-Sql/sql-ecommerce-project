# 📊 Project Overview

This project analyzes a large e-commerce sales dataset using SQL to uncover business insights, customer behavior, product performance, store performance, and sales trends.

The goal of the project is not simply to query the data, but to approach the dataset from a business intelligence perspective:

What can the data tell us about how the business is performing, who its customers are, what products generate the most value, and where opportunities for improvement exist?

The project uses a relational data structure consisting of a central sales fact table and supporting dimension data. SQL is used to combine these datasets, calculate key performance indicators, segment customers, identify high-performing products and stores, and investigate patterns within the sales data.

---
# 🎯 Project Objectives

The primary objectives of this project are to:

- Analyze overall e-commerce sales performance
- Identify the highest-value customers
- Measure customer purchasing behavior
- Identify top-performing products
- Evaluate store performance
- Analyze sales volume and revenue
- Calculate average order and purchase metrics
- Identify potential high-value customer segments
- Compare product demand using quantity and revenue
- Examine store-level performance
- Investigate sales trends using time-based data
- Identify unusual or potentially important patterns
- Demonstrate practical SQL data analysis skills
- Translate raw database records into actionable business insights
